added: **805 million triangle benchmark you can repeat**: `sculptforge --benchmark core-800m` runs the standard strokes and an orbit on the 805 million micro triangle head (core-100m, core-200m, core-400m and any core-<N>m work the same). Before it writes the scene file (0.6 GB, once) or opens anything it checks free memory (about 7 GB) and free disk (about 0.9 GB); with less it prints one line saying what it needs and what is free and exits, instead of running out of memory. The /benchmarks page lists the three measured runs (orbit 208 to 211 frames a second, 240 px stroke lag 63 to 64 ms at p99, on the entry-level budget) with the command, the memory and the disk it needs.
testers:
  - A computer with less than 7 GB free: `sculptforge --benchmark core-800m` prints "core-800m skipped: needs ~6.4 GB free, ... available. Close other apps and run again" and exits; nothing is written to the cache folder.
  - A computer with 16 GB or more free and 1 GB of disk: the same command writes the scene once, runs about a minute and saves the result JSON; the second run opens the scene file in about a second.
