whats_new: **Portable copy on a USB stick**: the Windows portable .zip now keeps everything in a `data` folder next to the program (settings, brushes, library, layouts, hotkeys, My Panel, recent files, logs), so the folder carries your workbench between PCs. Requested by Lex.
added: **Portable data folder** (requested by Lex): a `portable.txt` file (or a `data` folder) next to the program makes SculptForge keep all its data in `<program folder>/data`, created on the first run; without it nothing changes. The Windows portable .zip ships with `portable.txt`; on Linux (AppImage) and macOS an empty `portable.txt` next to the AppImage or the .app does the same. The first run of a portable copy on a computer that has SculptForge settings offers **Import my settings and brushes** (a copy; the installed copy is never written to). On a read-only stick the status line says so once and the computer's own folder is used for that session. One-click updates of the portable zip carry the `data` folder along; the install script's copy stays per-user.
testers:
  - Windows: unzip the portable .zip to a folder with spaces in its name (on a USB stick if you can), run bin\sculptforge.exe, change a setting (Edit > Preferences) and make a brush; a `data` folder appears next to the exe. Move the folder to another place or PC and run again: the setting and the brush are there.
  - Windows with the installed version used before: the first run of the portable copy asks to import; choose Import and your brushes and layout appear; the installed copy's settings are untouched.
  - Any OS: put a read-only stick or folder under the program: the status line says the folder can't be written and the computer's settings are used.
