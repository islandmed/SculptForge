SculptForge for studios

Every artist. $0 in licenses.

SculptForge is free and open source for any number of artists: no seats, no licence server, no accounts and no telemetry. It runs on Linux, Windows and macOS, works offline, and talks to Blender, Maya, Unreal and other sculpting apps.

Pipeline

Built to drop into the pipeline you already run

Blender add-on

The SculptForge Bridge add-on for Blender 4.2+ sends selected objects to SculptForge and back, with UVs, colours, mask and face sets.

Maya bridge New

A SculptForge shelf for Maya 2022+: send meshes, sculpt, send them back. Each object keeps its transform, parent and shading groups, in one undo step. Early: reports from Maya users are welcome.

Bridge

Exchanges Parts with another sculpting app through a shared bridge folder, with face groups, mask, vertex paint and UVs.

Unreal Engine

Send to Unreal pushes a sculpt into a running Unreal Editor 5.x: a static mesh with LODs, or a skeletal mesh with a morph target per layer. Sending again updates the asset in place.

File formats

OpenUSD (.usda, .usdz), FBX (reads any version, writes 7.4 binary), glTF / GLB, OBJ, PLY, STL and Bridge files. Exports are checked with OpenUSD's usdchecker and the Khronos glTF validator.

Linux, Windows, macOS

Native builds for all three, including .rpm for Fedora, RHEL, Rocky and Alma, .deb, AppImage, ARM64, a Windows installer and a universal macOS app.

Linux pipelines

Native Wayland and X11 from the same build: no XWayland, sharp on fractional and HiDPI scaling, pen pressure on both. RHEL- and Rocky-friendly packages (.rpm, Flatpak, tar.gz) and no licence server.

VFX Reference Platform

CY2026 and CY2027 builds (Rocky Linux 8 and 9, GCC 14, C++20, Python 3.13), tested in CI, plus a Rez package. Dependencies are linked statically, so nothing conflicts with your other tools.

Scripting and the farm

An import sculptforge Python module and sculptforge-cli run every editor operation headless: imports, remeshing, LODs, exports and offscreen turntable renders.

No accounts, no telemetry, offline

No sign-in, no licence server and nothing phones home. It works fully offline; AI features are optional and talk only to the service you choose. Studio brush libraries can load from a read-only share.

Licensing in plain terms: SculptForge is GPL-3.0-or-later. Use it on any number of machines, commercially; your artwork is yours; and you can modify it in-house without publishing your changes. The studio guide covers deployment, Rez, brush libraries and the Python API.

Studio questions

Plain answers

Is our build's code secret?

No. SculptForge is GPL-3.0, and so is your build: its source comes with it and is yours to share if you wish. There are no exclusive or secret features. What stays private is yours: your brushes, alphas, settings and files, which never go into public builds or packs, and your network, which your build never reaches out of.

What happens to the features we ask for?

They're built on your studio's branch first, in your private repository, and you get them in your build right away. Because everything is GPL-3.0, they may later reach everyone in a public release, credited to your studio.

What does "no outside connections" cover?

Your build opens no connection to the internet or your local network by default: no update check against our website, no AI services, no community gallery, no Discord presence. Its only connection is to your own release channel or internal mirror, plus anything you ask us to allow (for example your own ComfyUI server).

Which versions get security fixes?

The current release and one LTS line. Your studio is always on one of those two; when an LTS line ends, we help you move to the next one.

What counts as a custom item?

A brush, alpha, macro, keymap or pipeline preset, up to 3 a month. Bigger features are quoted separately before any work starts.

Is it priced per artist?

No. One flat rate covers the whole studio, however many artists you have. Every artist gets everything in Member.
