Pipeline

Built to drop into the pipeline you already run

Blender add-on

The SculptForge Bridge add-on for Blender 4.2+ sends selected objects to SculptForge and back, with UVs, colours, mask and face sets.

Maya bridge New

A SculptForge shelf for Maya 2022+: send meshes, sculpt, send them back. Each object keeps its transform, parent and shading groups, in one undo step. Early: reports from Maya users are welcome.

Send to ZBrush (GoZ-compatible exchange)

Reads and writes .GoZ and sends to and receives from a running ZBrush. A small ZBrush plug-in turns .ZTL files into Parts SculptForge opens directly.

Unreal Engine

Send to Unreal pushes a sculpt into a running Unreal Editor 5.x: a static mesh with LODs, or a skeletal mesh with a morph target per layer. Sending again updates the asset in place.

File formats

OpenUSD (.usda, .usdz), FBX (reads any version, writes 7.4 binary), glTF / GLB, OBJ, PLY, STL and .GoZ. Exports are checked with OpenUSD's usdchecker and the Khronos glTF validator.

Linux, Windows, macOS

Native builds for all three, including .rpm for Fedora, RHEL, Rocky and Alma, .deb, AppImage, ARM64, a Windows installer and a universal macOS app.

Linux pipelines

Native Wayland and X11 from the same build: no XWayland, sharp on fractional and HiDPI scaling, pen pressure on both. RHEL- and Rocky-friendly packages (.rpm, Flatpak, tar.gz) and no licence server.

VFX Reference Platform

CY2026 and CY2027 builds (Rocky Linux 8 and 9, GCC 14, C++20, Python 3.13), tested in CI, plus a Rez package. Dependencies are linked statically, so nothing conflicts with your other tools.

Scripting and the farm

An import sculptforge Python module and sculptforge-cli run every editor operation headless: imports, remeshing, LODs, exports and offscreen turntable renders.

No accounts, no telemetry, offline

No sign-in, no licence server and nothing phones home. It works fully offline; AI features are optional and talk only to the service you choose. Studio brush libraries can load from a read-only share.

Licensing in plain terms: SculptForge is GPL-3.0-or-later. Use it on any number of machines, commercially; your artwork is yours; and you can modify it in-house without publishing your changes. The studio guide covers deployment, Rez, brush libraries and the Python API.
