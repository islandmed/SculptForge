Benchmarks

How responsive sculpting is on real computers, measured by SculptForge's proof mode and submitted by the people who ran it. Each row is one mesh size of one run.

What the numbers mean. Proof mode plays a scripted pen stroke (240 pointer samples a second) through the same code a real pen goes through, on spheres of 5, 20 and 33 million triangles (100 million with enough memory). Frame is the time per frame: the median (p50) and the 95th / 99th percentile, the hitches you feel. Trails is how far the stroke on screen is behind the pointer: from the pointer sample to the frame that shows it handed to the display, in milliseconds, and the same distance along the path in pixels. Lower is better everywhere. Vertical sync is off unless noted. Every run also records a video with these numbers on screen.

Run it yourself

In SculptForge: Help > Benchmark. From a terminal: sculptforge --benchmark. Both write a JSON result and an MP4 of the run.

Submit a result

  1. Run it on a quiet machine (close other heavy programs).
  2. Check the file: python3 tools/benchmark/submit.py check result.json.
  3. Add it: python3 tools/benchmark/submit.py add result.json --name "your name" --video https://..., and open a pull request with the change to website/benchmarks/results.json, or attach the JSON to an issue.

The file format: docs/benchmark.md.
