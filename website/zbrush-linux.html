Sculpting on Linux

ZBrush doesn't run on Linux. This does.

ZBrush is Windows and macOS only, and Maxon doesn't support running it on Linux. SculptForge is a free, open-source sculpting app built for Linux as much as for Windows and macOS, with ZBrush's keys and gestures, so you can sculpt natively instead of fighting a compatibility layer.

Install on Linux Coming from ZBrush

Install

Every build is x86_64 or ARM64 and works on X11 and Wayland. You need a graphics driver with OpenGL 3.3, which any GPU from the last ten years has.

Ubuntu, Debian, Mint, Pop!_OS.deb · x86_64 Fedora, RHEL, Rocky, Alma.rpm · x86_64 Any LinuxAppImage · x86_64 ARM64 and VFX builds.deb, .rpm, AppImage for ARM64; CY2026 / CY2027 tarballs

Or in a terminal: curl -fsSL https://raw.githubusercontent.com/islandmed/SculptForge/main/install/install.sh | sh. On Arch, build it from packaging/arch/PKGBUILD with makepkg -si. Installing

The ZBrush way of working

SculptForge's defaults are ZBrush's: brushes on B and two letters, S U I O sliders, Ctrl to mask, Ctrl+Shift for polygroups, SubTools, subdivision levels, layers, dynamic topology, QRemesh-style retopology, VDM brushes, polypaint, texture painting and baking. A free ZBrush plug-in converts your ZTools, and GoZ moves models back and forth. SculptForge for ZBrush users

Questions

Can't I just run ZBrush in Wine?

Some people try. Maxon doesn't support it, so updates, plug-ins and licensing can break without warning, and you're on your own when they do. SculptForge is native and supported on Linux.

What about Blender?

Blender's Sculpt Mode is excellent and native too. It's a whole 3D suite, though, and sculpts its own way. SculptForge is only a sculpting app, with ZBrush's keys, and works alongside Blender through the add-on.

Is it free?

Yes, free and open source under the GPL-3.0, for commercial work too.
