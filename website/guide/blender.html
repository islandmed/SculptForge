Working with Blender

In short:

  • The SculptForge Bridge add-on sends selected objects to SculptForge with one click.
  • One click sends them back; transforms, materials and modifiers stay as they were.
  • Works through a shared folder on Linux, Windows and macOS, with Blender 4.2 or newer.

Keep Blender for the scene, rigging, shading and animation, and sculpt in SculptForge: the SculptForge Bridge add-on sends the selected objects from Blender to SculptForge with one click, and one click in SculptForge sends them back. The objects update in place in Blender: their transform, materials and modifiers stay as they were.

It works through files in a shared folder, on Linux, Windows and macOS, with Blender 4.2 or newer. Gaussian splats go the same way with Blender 5.3 or newer (Splats with Blender).

Install the add-on#

  1. Download sculptforge_bridge.zip from the latest release (or the SculptForge website).
  2. In Blender choose Edit›Preferences›Get Extensions, open the menu at the top right and choose Install from Disk..., then pick the zip. (You can also drag the zip into Blender's window.)
  3. The SculptForge tab appears in the 3D View's sidebar (press N). Send and Receive are also in the Object menu and in File›Import / Export.

Start SculptForge once after installing it: it records where it is installed, so the add-on can start it for you. If the add-on still can't find it (for example an AppImage you keep somewhere unusual), set its path in the add-on's preferences (Edit›Preferences›Add-ons›SculptForge Bridge).

Tip: Older Blender versions or a classic add-on install: sculptforge_bridge-<version>-legacy.zip installs through Edit›Preferences›Add-ons›Install from Disk. The add-on needs Blender 4.2 or newer either way.

A round trip#

  1. In Blender, select one or more mesh objects and click Send to SculptForge in the SculptForge tab. SculptForge starts, or, if it's already open, loads them within a second. Each object becomes a Part with the object's name, placed as it is in the Blender scene.
  2. Sculpt, paint, mask, divide, remesh: anything SculptForge does.
  3. In SculptForge choose File›Blender›Send to Blender. Every visible Part goes back.
  4. Blender picks it up by itself within a second (or click Receive from SculptForge). Each object that came from Blender is updated; a Part you added in SculptForge becomes a new object.

Sending again from Blender updates the same Parts: each update is one undo step on that Part in SculptForge, and each receive in Blender is one undo step there.

Blender is Z-up and SculptForge Y-up, both in metres; the add-on and SculptForge convert between them, so the model stands the same way in both and a round trip changes nothing. Objects with a negative scale (mirrored) come across the right way out.

When the topology doesn't change (you only sculpted, painted or masked), Blender's mesh keeps everything it had: its n-gons, edges, seams, creases, custom attributes and the other UV maps; only the positions, the active UV map, colour, mask and face sets are updated.

When the topology changes (Add Level, a remesh, Quad Remesh, Subdivide...), the object's mesh is rebuilt from what SculptForge sent. The object keeps its transform, materials, modifiers and the names of its active UV map and colour attribute; things tied to the old faces (material per face, seams, other UV maps, shape keys) can't follow and are reset.

Modifiers#

The Modifiers setting in the SculptForge tab chooses what an object with modifiers sends:

  • Keep live (the default): the mesh under the modifiers. They keep working in Blender on the sculpted mesh, for example a Mirror or a Subdivision Surface.
  • Apply: what you see, with the modifiers applied. When it comes back, the mesh holds their result, so the add-on turns those modifiers off (they stay on the object, switched off, if you want them again).

Settings#

In the SculptForge tab:

  • Receive automatically: after a send, load what SculptForge sends back as soon as it arrives (on by default). Off: click Receive from SculptForge yourself.

In SculptForge's File›Blender:

  • Receive automatically: load what Blender sends as soon as it arrives (on by default).

The add-on's preferences add the path of SculptForge and the exchange folder (below).

Classic sculpting keys in Sculpt Mode#

Sculpting in Blender too? Turn on The Classic sculpting keys in Sculpt Mode in the add-on's preferences (Edit›Preferences›Add-ons›SculptForge Bridge) and Blender's Sculpt Mode answers to the Classic sculpting keys where Blender has the same thing.

Turning it off removes them again, and Blender's own keys are back; so does disabling the add-on. The preferences list every key while it's on.

brushes map to Blender's closest: Standard = Draw, Sharp Crease = Draw Sharp, Clay Block = Clay Strips, Move = Grab, Move Elastic = Elastic Grab, Plane Trim = Trim (Scrape in Blender 4.2), Crease = Crease Sharp, MaskPen = Mask.

What Blender has no key for, or can't do:

  • I (Colour intensity): Blender's sculpt brushes don't paint.
  • Ctrl+drag on the model doesn't paint the mask with a round brush: Blender can't switch to the Mask brush for one stroke, so it draws a lasso mask (pick the Mask brush with B to paint it).
  • Dragging on the empty background doesn't rotate: a keymap can't tell the model from the background. Use the middle mouse button, or Blender's Emulate 3 Button Mouse.
  • Ctrl+click on the background (invert or clear the mask) and Ctrl+Shift+click (show all): use Ctrl+I, Alt+M and Alt+H.
  • B then two letters: a Blender menu takes one key at a time, so B opens the list and the letters filter it.
  • Alt+click a Part: Blender's objects aren't Parts (Alt+Q switches the object you sculpt).
  • Stroke types (Drag Stamp, Spray...): each Blender brush sets its stroke method in its Stroke panel.

These keys take Blender's place while they're on: F no longer sets the radius (that's S), B no longer draws a box mask, Ctrl+drag no longer inverts the brush (that's Alt), and Space no longer plays the animation in Sculpt Mode.

Vector displacement maps#

SculptForge's VDM brushes and Blender's use the same maps (see Vector displacement brushes):

  • From Blender: a map baked with Blender's VDM Brush Baker loads with Sculpt›Brush›Vector Displacement›Load VDM... as it is.
  • To Blender: Export EXR... writes the VDM brush's map. In Blender, in Sculpt Mode with a Draw brush: in the brush's Texture panel add a new image texture and open the EXR (set its Color Space to Non-Color), set Mapping to Area Plane, turn on Vector Displacement, then set the stroke method to Anchored and Strength to 1. Drag on the model to stamp it.

Splats with Blender#

Blender 5.3 draws Gaussian splats natively (a point cloud of the type 3D Gaussian Splat) and imports them, but it can't save them. With the add-on, splats go the same way meshes do, both ways, with everything that makes a splat look right: positions, sizes, rotations, opacity and colour including the view-dependent colour (spherical harmonics, up to degree 3).

It needs Blender 5.3 or newer; on older versions the splat buttons say so and the mesh bridge works as before. The file formats and what SculptForge does with a capture are in Gaussian splats.

From Blender to SculptForge

  1. Select the splat object (import a capture with File›Import›Stanford PLY (.ply), or just drop a .ply or .spz capture on Blender's viewport).
  2. Click Send to SculptForge. The capture loads next to your sculpt, as a reference, exactly as if you had opened the PLY there, placed as it is in the Blender scene. (A scene holds one capture: with several selected, the first goes.)

From SculptForge to Blender

  1. With splats loaded (a capture, or Sculpt to splats), choose File›Blender›Send to Blender.
  2. They arrive as a splat object named after the capture. Send again and the same object is updated in place, with its materials and modifiers; Flip, Turn 90 and Fit in SculptForge move the object, not the splats.

Drag and drop

  • Drop a .ply or .spz capture on Blender's viewport: Blender 5.3 imports it as splats by itself. The add-on adds the compact .splat format (the one many web viewers use) to that.
  • Drop a .ply, .splat, .glb or OpenUSD splat file on SculptForge's window: it loads as a reference.

Saving splats from Blender

File›Export›Gaussian Splats (.ply) saves the selected splat object as a standard 3D Gaussian Splatting PLY (Blender has no splat export of its own), which SculptForge, SuperSplat, Postshot and most tools open. By default it applies the object's transform; turn off Apply Object Transform to write the splats as they are in the object. A turned splat keeps its plain colour but loses its view-dependent colour, because that would point the wrong way.

Note: Blender's own Apply›All Transforms doesn't update a splat's rotations and spherical harmonics yet (Blender 5.3 release notes), so move splat objects with their transform and let SculptForge or the export apply it. Blender also assumes splats are in sRGB, so very faint, bright splats can look different from a splat viewer.

How it works#

The two programs share a folder in your user data: ~/.local/share/SculptForge/SculptForge/blender on Linux, %APPDATA%\SculptForge\SculptForge\blender on Windows, ~/Library/Application Support/SculptForge/SculptForge/blender on macOS. Each side writes its meshes there as Bridge files with a small list of the objects, and checks the other side's list once a second. Nothing goes over the network.

To use another folder, set it in the add-on's preferences and start SculptForge with the environment variable SCULPTFORGE_BLENDER_EXCHANGE set to the same folder.

From scripts and the MCP server: blender_send and blender_receive (both take folder=). Starting SculptForge with --blender loads what Blender last sent.

Limits and troubleshooting#

  • Blender as a Flatpak or Snap sees a different user data folder and may not be allowed to start other programs. Set the add-on's exchange folder to a folder both can reach, start SculptForge yourself with SCULPTFORGE_BLENDER_EXCHANGE set to it, and send.
  • Linked duplicates (objects sharing one mesh) all show the last one received.
  • Shape keys: the Basis and the keys named like SculptForge's layers are updated; other keys keep their shapes.
  • Subdivision levels don't go to Blender: it receives the level you're on (like Bridge files).
  • Sculpt layers arrive as shape keys (Basis plus one key per layer, with its name and weight), so the 52 facial shapes keep their ARKit names. Shape keys don't come back from Blender, and textures stay in SculptForge.
  • Nothing arrives in SculptForge? Check File›Blender›Receive automatically, or choose Receive from Blender. Nothing arrives in Blender? Click Receive from SculptForge; automatic receiving starts after the first send from that Blender session.
  • Splats need Blender 5.3 or newer. With several splat objects selected only the first is sent (SculptForge holds one capture); the compact .splat format loses a little precision in colour and rotation, and has no view-dependent colour.
  • Objects in Edit Mode or Sculpt Mode are updated too: the add-on switches to Object Mode for the update and back.
