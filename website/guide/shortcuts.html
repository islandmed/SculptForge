Keyboard and mouse

This chapter is the reference for every default keyboard shortcut and mouse gesture in SculptForge. Inside the app, F1 opens the same list as the Controls window, showing your own keys if you've changed any.

SculptForge has four key styles, chosen in Edit > Preferences > Input > Style (and by the Coming from question the first time SculptForge starts): SculptForge (the default for new installs), ZBrush-style, Blender and Maya. The main table shows the SculptForge style; the sections after it list what the ZBrush-style and Blender styles change. If you used an earlier version, your saved style is kept.

Changing shortcuts#

Every key below can be reassigned: hold Ctrl+Alt and click a button, then press the new key, or use Edit > Preferences > Hotkeys. Press Ctrl+Shift+I (Store Config) to keep your changes. See Customizing the interface.

On macOS, Cmd works wherever a shortcut says Ctrl. Single-letter shortcuts don't fire while you type in a text field.

Keyboard shortcuts#

The table lists the default shortcut of every action in the SculptForge style, grouped by palette. It is generated from SculptForge's action registry, the same source as the Controls window.

Clay2Builds up clay that fills the hollows first.
Clay Block0Square, flat-topped clay strokes for blocking in forms.
Crease6Cuts a sharp crease; Alt raises a ridge.

Inflate5Swells the surface outward along its normals.

Stroke#

ActionKeysWhat it does
Steady StrokeLSteady Stroke on or off, with every stroke type (Dots, Drag Stamp, Slide Stamp, Spray): the brush trails the cursor on a string and only moves once the string is taut, for steady lines without hand shake.

Tool#

ActionKeysWhat it does
Clear MaskCtrl+Shift+AUnmask everything (also: Ctrl+drag on the background, away from the model).
DivideCtrl+DAdd a subdivision level: four times the polygons, and the lower levels are kept, so you can step down to shape big forms and back up to the detail. Quads stay quads (Catmull-Clark). Smt off divides without smoothing.
Duplicate PartCtrl+Shift+DCopy the active Part, with its layers and attributes, and make the copy active (also in the Parts list's right-click menu).
Group MaskedCtrl+WTurn the masked part into a new face group and clear the mask (ZBrush Ctrl+W). With nothing masked, everything visible becomes one group.
Higher ResDStep one subdivision level up (more polygons, for detail). Edits made below carry the detail along.
Invert MaskCtrl+IMask what is unmasked and unmask what is masked (also: Ctrl+click the background).
Lower ResShift+DStep one subdivision level down (fewer polygons, for big forms). The detail of the higher levels is kept.
Mask AllCtrl+AMask the whole visible Part.
PreviewAShow the skin Make Mesh would build instead of the spheres (ZBrush's Preview). Turn it off to edit the spheres again.

UV Editor#

ActionKeysWhat it does
UV EditorAlt+UOpen the UV Editor: the Part's UV layout in 2D over the UDIM tiles. Select vertices, edges, faces or islands (here or on the model), move, rotate and scale them, mark seams, unwrap, pack, set texel density and lay islands into trim sheet strips. Stretch and texel density show live on the model while you edit.

View#

ActionKeysWhat it does
Lock cameraShift+LLock the camera for left-drags: a drag that starts on the background sculpts once it reaches the model instead of turning the view (Preferences > Input > Start strokes off the model, #62). The status bar shows CAMERA LOCKED while it is on. Right-drag or Alt+drag still move the view. Shift+L turns it on and off.

ZBrush-style keys#

With Edit > Preferences > Input > Style on ZBrush-style (also at the top of the Controls window, F1, or ZBrush in the first-start Coming from question), the keys and gestures work as in ZBrush. Store Config (Ctrl+Shift+I) keeps the choice. Compared with the table above, these change:

ToSculptForge styleZBrush-style
Pick one of the first ten brushes1 to 9, 0 (Standard, Clay, Smooth, Move ...)No key: the number keys are free
Save SnapshotNo key9 (ZBrush's QuickSave)
Slider at the cursor on IIntensity (as U)RGB Intensity
Ctrl+drag on the background with nothing maskedZoomsDraws a mask rectangle (one that misses the model clears the mask)
Zoom drags (Ctrl+right-drag, Alt+drag then release)Up zooms inUp zooms out

Everything else, from the B brush letters and S / U / O to the Ctrl and Ctrl+Shift gestures, is the same in both styles. The Maya style keeps these ZBrush-style keys and changes only the view controls (Alt+left, middle and right drags).

Maya keys#

With Edit > Preferences > Input > Style on Maya (#32), the view works as in Maya, on the model or beside it, as long as Alt is the only key held:

ToMaya style
RotateAlt+left-drag
PanAlt+middle-drag
ZoomAlt+right-drag sideways: right zooms in, left zooms out, as Maya's own dolly
Invert the brush (subtract)Hold Ctrl while sculpting
Paint a mask / erase itCtrl+Alt+drag / Ctrl+Alt+Shift+drag
SmoothHold Shift while sculpting

Maya's default dolly follows a sideways drag, so that is the default here too. Edit > Preferences > Input > Zoom drag switches it to Up and down (drag up to zoom in) if you set Maya up that way. Invert zoom, in every style, turns zoom drags around (the mouse wheel stays as it is).

Choosing the Blender style also sets Rotation to Turntable, as Blender orbits; change it back under Edit > Preferences > Input if you like. Blender's face sets are SculptForge's face groups, and its brushes map to the nearest SculptForge brush. Symmetry X, Paint and the material picker have no key in the Blender style (they are on the shelves); give them one with Ctrl+Alt+click. Laptops without a numpad: turn on Edit > Preferences > Input > Emulate Numpad and the number row works as the numpad.

The numpad views (Numpad 1, 3, 7, 5 ...) work in every style.

Your own Blender keymap#

If you changed Blender's keys, export them in Blender (Edit > Preferences > Keymap, the Export... button next to the keymap name) and in SculptForge choose Import Blender keymap... under Edit > Preferences > Input or at the top of the Controls window. SculptForge switches to the Blender style and takes, from the file's 3D View and Sculpt keymaps, the keys of every action it has an equivalent for: the views, the brushes above, the radius and strength, the mask, hiding, subdivision levels, undo and redo. Mouse buttons and keys for things SculptForge doesn't have are left alone; the status bar says how many keys it took. The file is read as text and never run. Ctrl+Shift+I (Store Config) keeps the keys; Restore Standard UI goes back to the defaults.

ZBrush keys that work differently#

ZBrush's keys and gestures work in SculptForge with the ZBrush-style keys. The few that differ even then, because the feature works differently or doesn't exist yet:

ZBrushSculptForge
P (perspective)P is the Paint brush; Numpad 5 switches to an orthographic view
T (Edit mode)Always in Edit mode: there is no 2.5D canvas
W / E / R (Transpose line)The Gizmo (see Gizmo)
1, 2, 3 (replay and record strokes)Not yet
N (list the SubTools)Tool > Parts in the right tray
F1 to F6 (pop-ups)F1 is the Controls window, F3 the command palette; B, M and the left-shelf tiles pop up brushes, strokes, alphas and materials
Ctrl+E (edge loop), Ctrl+U (reload ZScript)Export GLB and Send to Unreal
H (hide the ZScript window)` toggles the console

See Coming from ZBrush for the whole list.
